방법 ①

상황별 프롬프트 — AI 서비스에 복사·붙여넣기

Gemini, Claude, ChatGPT 같은 일반 AI 서비스를 쓰신다면 여기서 시작. 상황을 클릭하면 프롬프트가 열립니다. 복사해서 평소 쓰시는 AI에 붙여넣으면 끝.

AI 서비스 사용 팁

복사한 프롬프트는 어느 AI 서비스든 잘 됩니다. 한국 교사가 많이 쓰는 3가지 사용 팁:

🟢 Gemini

Google의 AI 서비스. 무료(Gemini 3.0 Flash) + 유료 Pro/Ultra. HWP·HWPX 공식 지원(2024-08~, 10파일 × 100MB) + PDF·DOCX·TXT·PPTX·이미지. 한국 교사 친화적. Workspace 학교 계정은 관리자가 Gemini 앱 활성화 필요.

Gemini 열기 →
🟠 Claude

Anthropic의 Claude. 1M 토큰 컨텍스트(Sonnet 4.6 / Opus 4.7) — 교과서 단원 통째로 처리 강점. 한국어 자연스러움. 무료(claude.ai) 시작. PDF·DOCX·이미지 첨부 + Artifacts. HWPX는 직접 미지원 — PDF 변환 권장(Claude Code + HWP-MCP 우회도 가능).

Claude 열기 →
⚫ ChatGPT

OpenAI의 ChatGPT. 무료 기본 GPT-5.3 Instant, 한도 내 GPT-5.5도 사용. HWP·HWPX 지원(500페이지+ 대용량 가능). 긴 인터뷰 흐름 안정적. PDF·DOCX·이미지 첨부 가능. Custom GPT 생성은 Plus(유료) 필요.

ChatGPT 열기 →
방법 ②

스킬로 한 번에 설치 — CLI/Agent 도구 사용자용

Claude Code, Codex, Google Antigravity 같은 AI 코딩/에이전트 도구를 쓰신다면, 17개 스킬 전체를 한 번에 설치할 수 있습니다. 설치 후엔 "k-teacher-workflow-router로 내 요청을 분석해줘" 한 줄로 자동 진입.

🤖 Claude Code

Anthropic 공식 AI 코딩 CLI. SKILL.md 자동 감지.

git clone https://github.com/pblsketch/k-teacher-skills
cd k-teacher-skills
.\scripts\install-claude.ps1

설치 위치: ~/.claude/skills/

🟦 Codex

OpenAI Codex CLI. SKILL.md 동일 포맷 사용.

git clone https://github.com/pblsketch/k-teacher-skills
cd k-teacher-skills
.\scripts\install-codex.ps1

설치 위치: ~/.codex/skills/

🟢 Antigravity

Google Antigravity 에이전트 IDE. SKILL.md 동일 포맷.

git clone https://github.com/pblsketch/k-teacher-skills
cd k-teacher-skills
.\scripts\install-antigravity.ps1

글로벌: ~/.gemini/antigravity/skills/
워크스페이스: <workspace>/.agents/skills/

📂 셋 다 설치: 
.\scripts\install-all.ps1
