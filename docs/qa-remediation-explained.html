K-Teacher Skills,
무엇이 더 안전해졌을까?

이번 개선의 핵심은 새 기능을 화려하게 늘린 것이 아닙니다. 여러 문서가 서로 다르게 말하지 않도록 맞추고, 교사의 최신 판단이 정확히 반영되도록 안전장치를 강화한 작업입니다.

30초 요약

한마디로 말하면

“지금은 맞지만 나중에 어긋날 수 있는 상태”에서, “어긋나면 자동으로 멈추고 알려주는 상태”로 바뀌었습니다.

개선 전

  • 여러 안내 파일이 지금은 같아도, 나중에 따로 바뀌는 것을 완전히 잡지 못함
  • 교사가 승인한 뒤 취소했을 때, 예전 승인이 남아 있을 가능성을 충분히 검사하지 못함
  • 한 곳을 기준 문서라고 선언했지만, 실제 검사가 그 기준을 직접 보지는 않음

개선 후

  • 공식 기준과 공개 안내 파일을 글자·순서까지 대조하고, 다르면 중단
  • 같은 사안의 판단 기록을 시간순으로 다시 계산해 가장 최신 판단만 반영
  • 17개 스킬의 관문 규칙을 하나의 공식 대장과 직접 비교

핵심 변화 3가지

학교 업무에 빗대어 이해하기

개발 용어보다 ‘공식 대장, 결재 이력, 출입 관문’이라는 세 가지 비유로 보면 쉽습니다.

CHANGE01

공식 대장과 배포 문서가 완전히 같은지 확인

학교의 공식 업무분장표와 교무실·홈페이지에 게시한 명단이 한 글자라도 다르면 경고하는 것과 같습니다.

이전

이름, 버전, 개수처럼 일부 항목만 확인했습니다. 겉으로는 맞아 보여도 세부 순서나 설명이 달라질 수 있었습니다.

→
현재

모든 항목, 값, 순서를 공식 대장과 통째로 비교합니다. 항목이 하나 더 있거나 순서가 바뀌어도 검사가 멈춥니다.

실제로 일부러 틀려 본 사례

17개 스킬 중 한 경로를 바꾸거나, 설명을 다르게 쓰거나, 마켓 목록을 하나 더 넣거나, 태그 순서를 뒤집었습니다. 여섯 가지 고의 오류를 모두 잡았고, 시험 뒤 원본은 정확히 복원됐습니다.

CHANGE02

교사의 ‘가장 최신 판단’만 유효하게 반영

처음에 “승인”했더라도 나중에 “취소” 또는 “반려”했다면, 예전 결재가 다시 살아나면 안 됩니다.

이전

승인 기록 하나하나는 확인했지만, 같은 사안에 여러 판단이 쌓였을 때 시간순으로 최신 결정을 다시 계산하는 검사가 부족했습니다.

→
현재

같은 사안의 기록을 시간순으로 모아 가장 최신 결정을 찾습니다. 최신 결정이 취소·반려·무효이면 작업을 안전하게 멈춥니다.

판단 이력 예시

10:00 승인 → 10:15 취소 → 결과물 생성 중단

같은 시각에 상충하는 결정이 둘 이상 있으면 임의로 고르지 않고 ‘모호함’으로 처리해 멈춥니다. 교사의 판단권을 추측으로 대체하지 않기 위한 장치입니다.

CHANGE03

17개 스킬의 관문 규칙을 하나의 기준에 연결

교실마다 따로 만든 규칙표가 아니라, 학교의 공식 생활 규정을 모든 교실이 직접 확인하도록 바꾼 것입니다.

이전

공식 기준 파일이 있었지만, 중간 매핑표와 각 스킬 문서끼리만 비교되는 부분이 있었습니다.

→
현재

공식 대장 → 매핑표 → 각 스킬 문서를 직접 연결해 17개 전체를 검사합니다. 어느 한 곳만 바뀌면 검사가 실패합니다.

왜 중요한가?

사용자가 라우터로 시작하든 특정 스킬로 바로 들어가든, 필요한 질문·확인·승인 단계를 건너뛰지 않게 만드는 기반입니다.

작동 방식

이제는 이렇게 확인합니다

변경을 무조건 허용하는 것이 아니라, 공식 기준과 최신 교사 판단을 모두 확인한 뒤 다음 단계로 넘어갑니다.

1. 공식 기준 읽기

스킬 목록, 관문 규칙, 공개 정보의 기준이 되는 대장을 읽습니다.

2. 최신 판단 계산

같은 사안의 승인·취소·반려 기록을 시간순으로 정리합니다.

3. 일치할 때만 진행

기준과 문서가 같고 최신 교사 판단이 승인일 때만 다음 작업을 허용합니다.

검증 결과

“정상 작동”만 본 것이 아닙니다

안전장치는 정상 자료가 통과하는 것만으로 충분하지 않습니다. 일부러 잘못된 자료를 넣었을 때 확실히 멈춰야 합니다.

화재경보기처럼 시험했습니다

화재경보기는 평소 조용하다고 좋은 것이 아닙니다. 연기를 넣었을 때 울려야 합니다.

이번 검증도 같은 방식입니다. 스킬 경로, 마켓 목록, 승인 시각, 관문 규칙을 일부러 틀리게 만든 뒤 시스템이 거부하는지 확인했습니다.

결과: 정상 자료는 통과했고, 고의 오류는 모두 차단했습니다.

남은 과제

완벽하다는 뜻은 아닙니다

이번 개선 범위의 막힘은 모두 해결됐습니다. 다만 제품이 성장하면서 다음 단계에서 보강할 항목은 남아 있습니다.

추후 · 중간 우선순위

실제 HWPX·DOCX 파일 왕복 검사

현재는 문서에서 추출됐다고 가정한 JSON 자료로 내용 일치를 검사합니다. 실제 렌더러가 완성되면 실제 파일을 만들고 다시 읽는 검사가 필요합니다.

추후 · 중간 우선순위

검사 기준의 추가 중앙화

일부 기대값이 검사 프로그램 안에도 중복돼 있습니다. 앞으로 더 많은 기준을 공식 registry에서 직접 읽게 만들 수 있습니다.

추후 · 낮은 우선순위

설명 문서의 구조적 검사

일부 안내 문서는 핵심 문구가 있는지만 확인합니다. 제목과 위치까지 구조적으로 확인하는 방식으로 강화할 수 있습니다.

추후 · 낮은 우선순위

다양한 Python 환경 지원

현재 검사는 이 환경의 python3 명령을 기준으로 합니다. 운영체제별 실행기 차이를 흡수하면 이식성이 좋아집니다.

용어 풀이

개발 용어를 쉬운 말로

원문 보고서를 볼 때 필요한 최소한의 용어만 정리했습니다.

Registry
스킬 목록과 규칙을 모아 둔 ‘공식 대장’입니다.
Validator
자료가 정해진 규칙을 지켰는지 확인하는 ‘자동 점검표’입니다.
Fixture
정상·오류 상황을 재현하기 위해 미리 만든 ‘시험용 예시 자료’입니다.
Fail-closed
판단하기 어려우면 임의로 통과시키지 않고 안전하게 멈추는 원칙입니다.
Drift
같아야 할 여러 문서가 시간이 지나며 서로 달라지는 현상입니다.
Supersession
과거 판단보다 최신 판단을 우선하여 효력을 다시 계산하는 방식입니다.

결론

더 많은 자동화보다,
더 믿을 수 있는 자동화

이번 개선은 AI가 교사의 판단을 대신하도록 만든 작업이 아닙니다. 오히려 공식 기준과 교사의 최신 결정을 확인하지 못하면 AI가 멈추도록 만든 작업입니다. 따라서 K-Teacher Skills는 이전보다 문서 간 불일치와 오래된 승인 재사용에 강해졌습니다.
