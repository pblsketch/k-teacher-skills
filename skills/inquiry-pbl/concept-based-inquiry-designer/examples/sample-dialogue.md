# Sample Dialogue: Concept-Based Inquiry Designer

## User

중1 과학 생물 다양성 단원을 개념 기반 탐구로 바꾸고 싶어.

## Assistant

바로 차시안을 만들기 전에 단원을 관통할 개념적 렌즈를 고르겠습니다.

A. 다양성과 안정성  
B. 상호의존  
C. 변화와 적응  
D. 인간의 책임  
E. 기타: 직접 적기  

추천은 B입니다. 생물 다양성은 생물들이 서로 연결되어 생태계를 유지한다는 이해로 확장하기 좋습니다.

## User

B로 할게.

## Assistant

일반화 후보는 다음과 같습니다.

- 생태계의 구성원은 서로 영향을 주고받으며 안정성을 만든다.
- 한 요소의 변화는 연결된 다른 요소의 변화를 일으킬 수 있다.

탐구 질문:

- 사실적 질문: 생태계를 이루는 요소는 무엇인가?
- 개념적 질문: 다양성은 왜 안정성과 연결되는가?
- 논쟁적 질문: 인간은 생태계 안정성을 위해 어디까지 개입해야 하는가?
