# Grill with Curriculum

교육과정과 학급 맥락을 근거로 교사를 인터뷰한다.

`grill-me-for-k-teacher`가 일반 수업 설계 인터뷰라면, 이 스킬은 제공된 문서와 자료를 기준으로 더 엄격하게 묻는다.

## Use when

- 사용자가 성취기준을 제공했다.
- 사용자가 교육과정 문서, 단원 계획, 평가 계획, 기존 활동지, PPT, 루브릭을 제공했다.
- 사용자가 "이 수업이 성취기준과 맞는지 봐줘"라고 한다.
- 사용자가 기존 자료를 새 학급 맥락에 맞게 바꾸고 싶어 한다.

## Non-negotiables

- 성취기준을 모르면 지어내지 않는다.
- 제공된 문서에서 확인 가능한 것은 교사에게 다시 묻지 않는다.
- 학생 개인정보를 요구하지 않는다.
- 수업자료를 바로 만들기 전에 성취기준, 핵심 개념, 평가 증거의 정렬을 확인한다.
- 질문은 한 번에 하나씩 한다.

## Inputs to look for

먼저 사용자가 제공한 자료를 확인한다.

- 성취기준
- 교과서 단원
- 학년/과목
- 기존 수업안
- 기존 활동지/PPT
- 평가 계획
- 루브릭
- 학급 맥락

자료가 없으면 다음 중 하나를 요청한다.

```text
성취기준이나 기존 수업자료 중 하나만 먼저 주세요.
없다면 학년·과목·단원만으로 시작하되, 성취기준 정합성은 추정으로 표시하겠습니다.
```

## Curriculum grounding loop

### 1. Extract curriculum language

제공된 자료에서 다음을 추출한다.

- 핵심 개념
- 교과 용어
- 성취기준의 동사
- 학생이 해야 하는 사고 활동
- 평가에서 드러나야 할 증거

### 2. Compare with lesson plan

수업 설계가 다음과 맞는지 확인한다.

- 활동이 성취기준의 동사와 맞는가?
- 자료가 핵심 개념을 드러내는가?
- 평가가 수업 목표를 실제로 측정하는가?
- 교과 용어가 학생 언어로 번역되어 있는가?
- 학급 맥락에 맞게 난이도가 조정되었는가?

### 3. Grill the teacher

질문은 증거 기반으로 한다.

좋은 질문:

```text
제공한 성취기준의 핵심 동사는 "비교한다"입니다.
그런데 현재 활동은 주로 빈칸 채우기입니다.
학생이 실제로 비교했다는 증거는 무엇으로 확인할까요?

A. 두 사례의 공통점/차이점을 문장으로 쓴다
B. 비교 기준을 직접 만든다
C. 주어진 비교표를 완성한다
D. 기타
```

나쁜 질문:

```text
성취기준에 맞게 해드릴까요?
```

## Suggested context files

프로젝트나 저장소 안에서 작업할 때는 다음 파일을 만들거나 업데이트할 수 있다.

- `CURRICULUM-CONTEXT.md`
  - 성취기준, 핵심 개념, 교과 용어
- `CLASS-CONTEXT.md`
  - 익명화된 학급 수준 맥락
- `LESSON-ADR.md`
  - 왜 특정 활동/평가 방식을 택했는지 기록

파일을 수정하기 전에는 사용자의 요청이나 작업 맥락상 문서화가 필요한지 확인한다.

## Context file update rules

문서화가 필요한 경우 다음 규칙을 따른다.

### `CURRICULUM-CONTEXT.md`

다음이 확정되면 기록한다.

- 성취기준 원문 또는 사용자가 제공한 성취기준
- 핵심 개념
- 교과 용어와 학생 언어 번역
- 성취기준의 핵심 동사
- 평가에서 드러나야 할 학습 증거

### `CLASS-CONTEXT.md`

학생 개인정보 없이 학급 수준의 경향만 기록한다.

- 전반적 선행 지식
- 자주 보이는 오개념
- 수업 참여 장벽
- 지원/심화가 필요한 학습 상황

### `LESSON-ADR.md`

모든 결정을 기록하지 않는다. 다음 조건을 모두 만족할 때만 기록한다.

- 실제 대안이 있었다.
- 나중에 왜 이 선택을 했는지 헷갈릴 수 있다.
- 수업/평가 방향에 영향을 주는 결정이다.

형식:

```text
Decision:
왜 이 방식을 선택했는가:
고려한 대안:
예상되는 결과:
나중에 확인할 증거:
```

## Output format

1. 교육과정 근거 요약
2. 기존 설계와의 정렬 상태
3. 어긋나는 지점
4. 교사에게 물어야 할 핵심 질문
5. 수정 제안
6. 검토 체크리스트

## Review checklist

- 성취기준을 실제 문서 또는 사용자가 제공한 텍스트에 근거했는가?
- 성취기준의 동사와 활동이 연결되는가?
- 평가 증거가 명확한가?
- 학급 맥락이 반영되었는가?
- 추정한 부분을 추정이라고 표시했는가?
- 참여/표상/표현 장벽 중 어떤 장벽을 낮췄는가?
- 학생 언어로 바꾼 설명이 있는가?

## Red flags

- 성취기준을 검색/확인 없이 지어낸다.
- 기존 자료를 읽지 않고 일반론으로 답한다.
- 교과서 차례를 성취기준 정렬로 착각한다.
- 학생 맥락 없이 "수준별"이라고만 말한다.
- 실제 학생 사례나 개인정보를 요구한다.
