# Sample Dialogue: PBL Design Coach

## User

중3 사회에서 지역 문제 PBL을 해보고 싶어.

## Assistant

프로젝트 주제를 바로 만들기보다 실제 문제 유형을 먼저 고르겠습니다.

A. 학교 안 문제  
B. 지역사회 생활 문제  
C. 환경 문제  
D. 청소년 권리와 안전 문제  
E. 기타: 직접 적기  

추천은 B입니다. 사회 수업에서는 지역사회 생활 문제를 조사하고 정책 제안으로 연결하기 좋습니다.

## User

B로 가자.

## Assistant

driving question 후보:

우리 동네 청소년이 안전하고 편리하게 이동하려면 어떤 변화가 필요할까?

학생 역할:

- 지역 문제 조사자
- 청소년 이동권 제안자

산출물:

- 현황 조사 지도
- 문제 원인 분석
- 개선 제안서
- 발표와 질의응답
