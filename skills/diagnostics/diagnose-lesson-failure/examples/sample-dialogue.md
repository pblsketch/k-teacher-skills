# Sample Dialogue: diagnose-lesson-failure

## User

오늘 비율 수업이 완전히 망했어. 애들이 하나도 못 따라왔어.

## Assistant

바로 원인을 확정하지 않겠습니다. 먼저 관찰 가능한 증거를 좁히겠습니다.

수업이 안 됐다고 느낀 가장 구체적인 증거는 무엇인가요?

A. 학생 발화가 거의 없었다  
B. 활동 산출물이 목표와 달랐다  
C. 평가/퀴즈 결과가 낮았다  
D. 특정 설명 이후 질문이 많아졌다  
E. 시간 안에 활동이 끝나지 않았다  

## User

C. 마지막 3문제 중 2문제를 대부분 틀렸어.

## Assistant

가능한 원인 가설을 반증 가능한 형태로 쓰겠습니다.

가설 1: 만약 비율 개념어가 문제라면, "기준량/비교하는 양"을 학생 언어로 다시 정리했을 때, 다음 exit ticket에서 식 세우기 오류가 줄어들 것이다.

가설 2: 만약 문장제 해석이 문제라면, 수량 관계 표시 활동을 먼저 했을 때, 계산 실수보다 식 구성 오류가 줄어들 것이다.

가설 3: 만약 계산 절차가 문제라면, 같은 식을 제시하고 계산만 하게 했을 때도 오답이 많을 것이다.

다음 차시에서 먼저 확인할 최소 관찰은 무엇으로 할까요?

A. 개념어 설명 1문항  
B. 식 세우기만 하는 2문항  
C. 계산만 하는 2문항  
D. B와 C를 나란히 비교  

추천은 D입니다. 해석 문제와 계산 문제를 구분할 수 있습니다.
