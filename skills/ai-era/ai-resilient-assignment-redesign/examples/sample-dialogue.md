# Sample Dialogue: AI-Resilient Assignment Redesign

## User

중2 사회에서 지역 문제 해결 보고서 과제가 있는데, 학생들이 ChatGPT로 보고서를 복붙할까 봐 걱정돼.

## Assistant

바로 새 과제를 만들기보다, 먼저 AI로 대체되기 쉬운 지점을 진단하겠습니다.

확인을 위해 세 가지만 알려주세요.

A. 현재 과제 안내문 일부  
B. 수행 기간과 제출물  
C. 가장 걱정되는 AI 사용 방식  

가능한 것부터 주시면 됩니다.

## User

지역 문제를 하나 정해서 원인, 해결 방안, 기대 효과를 보고서로 쓰는 과제야. 2주 동안 하고 보고서만 제출해.

## Assistant

현재 과제는 AI 대체 가능성이 높습니다. 이유는 주제 선정, 원인 분석, 해결 방안 제안이 모두 일반 프롬프트로 생성될 수 있고, 학생의 실제 조사 과정이 드러나지 않기 때문입니다.

재설계 방향은 세 가지를 조합하겠습니다.

A. 실생활·지역 연결  
B. 과정 중심 평가 강화  
E. SHIFT 비판적 사고 통합  

추천 AI 활용 수준은 Level 2~3입니다. AI는 아이디어 탐색과 초안 비교에는 쓸 수 있지만, 최종 보고서는 학생의 현장 관찰, 인터뷰 메모, 수정 이력, 성찰을 바탕으로 완성해야 합니다.

## User

좋아. 학생 안내문까지 만들어줘.

## Assistant

학생용 안내문, 프롬프트 로그, SHIFT 성찰지를 함께 만들겠습니다. 과정 평가는 60%, 최종 산출물은 40%로 두겠습니다.

최종안에는 다음을 포함합니다.

1. H→AI→H 과제 흐름
2. GRASPS 과제 설명
3. AI 사용 가능 범위
4. 프롬프트 로그 양식
5. SHIFT 성찰지
6. 발표·질의응답 확인 질문
7. AI 오용 대응 기준
