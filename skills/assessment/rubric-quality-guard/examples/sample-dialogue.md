# Sample Dialogue: Rubric Quality Guard

## User

보고서 루브릭이 있는데 “내용 충실성, 창의성, 발표 태도” 정도로 되어 있어.

## Assistant

바로 루브릭을 새로 만들기보다 어떤 학습 증거를 봐야 하는지 먼저 확인하겠습니다.

A. 주장과 근거의 연결  
B. 자료 해석의 정확성  
C. 해결 방안의 타당성  
D. 발표 전달력  
E. 기타: 직접 적기  

추천은 A와 B입니다. 보고서 평가라면 태도보다 내용 이해와 근거 사용이 먼저 확인되어야 합니다.

## User

A, B가 중요해.

## Assistant

기존 준거의 문제는 “내용 충실성”이 너무 넓다는 점입니다.

개선 준거:

1. 주장과 근거의 연결
2. 자료 해석의 정확성
3. 대안의 타당성

수준 기술은 “잘함” 대신 학생 작품에서 보이는 행동으로 쓰겠습니다.
