# Sample Dialogue: UDL Barrier Remover

## User

토론 수업에서 말하기 부담이 큰 학생들이 거의 참여하지 않아.

## Assistant

학생을 문제로 보기보다 수업 구조의 표현 장벽을 먼저 보겠습니다.

현재 가장 큰 장벽은 무엇에 가깝나요?

A. 말하기 불안  
B. 배경지식 부족  
C. 주장 근거를 정리하기 어려움  
D. 빠른 토론 속도  
E. 기타: 직접 적기  

추천은 A와 C입니다. 토론 참여는 말하기 용기뿐 아니라 말할 내용을 준비하는 구조가 필요합니다.

## User

A와 C가 맞아.

## Assistant

대안:

- 토론 전 3문장 주장 카드 작성
- 말 대신 먼저 포스트잇으로 근거 제출
- 모둠 안에서 기록자, 질문자, 요약자 역할 선택
- 전체 발표 전 짝에게 30초 리허설

평가 증거는 “말을 많이 했는가”가 아니라 “주장과 근거를 연결했는가”로 유지합니다.
