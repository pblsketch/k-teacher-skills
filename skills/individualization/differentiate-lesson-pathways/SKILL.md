# Differentiate Lesson Pathways

개별화는 목표를 낮추는 일이 아니다. 같은 핵심 목표에 도달하는 경로와 지원을 다르게 설계한다.

## Non-negotiables

- 학생을 고정된 수준으로 낙인찍지 않는다.
- 기초 수준을 단순히 양 줄이기로 만들지 않는다.
- 먼저 공통 학습 목표와 필수 평가 증거를 확인한다.
- 질문할 때는 가능한 한 3~5개의 선택지와 `기타: 직접 적기`를 제공한다.
- 질문을 더 할지, 수준별 경로를 설계할지는 `../../../references/interview-readiness.md`의 readiness gate로 판단한다.
- 학생 개인정보, 실명, 민감정보를 요구하지 않는다.
- 참여/표상/표현 장벽을 낮추는 선택지를 포함한다.

## Workflow

### 1. Fix the common target

모든 경로가 공유할 목표를 정한다.

- 핵심 개념
- 필수 기능
- 최소 평가 증거
- 공통 성공 기준

### 2. Diagnose barriers

학생이 막힐 지점을 구분한다.

- 어휘 장벽
- 배경지식 장벽
- 읽기/쓰기 부담
- 추상화 수준
- 협업 부담
- 표현 방식 제한

### 3. Design pathways

`../../../references/differentiation-patterns.md`를 참고해 경로를 설계한다.

- 기초: 구조화된 지원과 예시 제공
- 표준: 핵심 목표를 독립적으로 수행
- 심화: 전이, 비교, 비판, 창안 확장

### 4. Add choice without losing rigor

선택판은 아무거나 고르는 메뉴가 아니다. 모든 선택지가 같은 목표와 평가 증거에 연결되어야 한다.

### 5. Plan flexible grouping

소그룹은 고정 수준반이 아니라 일시적 지원 구조로 제안한다.

## Output format

1. 공통 학습 목표
2. 필수 평가 증거
3. 예상 학습 장벽
4. 기초/표준/심화 경로
5. 선택형 과제 또는 choice board
6. 소그룹 지원 계획
7. 공통 루브릭
8. 참여/표상/표현 장벽 조정안

## Review checklist

- 모든 경로가 같은 핵심 목표를 향하는가?
- 기초 경로가 유치하거나 단순 반복이 아닌가?
- 심화 경로가 양 증가가 아니라 사고 깊이 확장인가?
- 학생 선택권이 있으면서 평가 기준은 공통인가?
- 개인정보를 요구하지 않는가?
- readiness gate를 통과했거나 미확정 항목을 표시했는가?

## Red flags

- 수준별을 상/중/하 낙인으로 표현한다.
- 기초 학생에게 목표 자체를 삭제한다.
- 심화 학생에게 문제 수만 늘린다.
- 공통 평가 증거가 없다.
