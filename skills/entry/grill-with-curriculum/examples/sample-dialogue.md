# Sample Dialogue: grill-with-curriculum

## User

성취기준은 "자료를 해석하여 사회 현상의 특징을 설명한다"야. 기존 활동지는 자료를 보고 빈칸을 채우는 형태야. 이게 괜찮을까?

## Assistant

제공한 성취기준의 핵심 동사는 "해석하여 설명한다"입니다. 현재 활동은 "빈칸 채우기"에 가깝습니다.

학생이 실제로 자료를 해석했다는 증거는 무엇으로 확인할까요?

A. 자료에서 변화 경향을 찾아 문장으로 설명한다  
B. 빈칸에 정답 단어를 쓴다  
C. 자료의 수치를 그대로 옮긴다  
D. 교사가 설명한 내용을 따라 적는다  

추천은 A입니다. 성취기준의 "해석"은 자료의 의미를 자기 말로 설명하는 행동으로 드러나야 합니다.

## User

A가 맞아. 그런데 학생들이 그래프 읽기를 어려워해.

## Assistant

그렇다면 `CLASS-CONTEXT.md`에는 "그래프 읽기에서 축과 변화 방향 해석이 어렵다"라고 학급 수준의 익명화된 맥락으로 기록할 수 있습니다.

다음 결정이 필요합니다.

그래프 해석 장벽을 낮추기 위해 무엇을 먼저 제공할까요?

A. 축 이름과 단위 확인 질문  
B. 변화 방향을 고르는 선택지  
C. 해석 문장 틀  
D. A → B → C 순서의 발판  

추천은 D입니다.

## User

D로 하자.

## Assistant

Lesson decision record 후보입니다.

Decision: 빈칸 채우기 활동을 그래프 해석 발판 활동으로 바꾼다.  
왜 이 방식을 선택했는가: 성취기준의 핵심 동사 "해석하여 설명한다"와 기존 활동이 어긋났기 때문이다.  
고려한 대안: 빈칸 유지, 서술형만 추가, 그래프 설명 강의 추가  
예상되는 결과: 학생이 자료의 변화 방향과 의미를 문장으로 설명한다.  
나중에 확인할 증거: exit ticket에서 변화 방향과 사회 현상 설명이 함께 나타난다.
