# Sample Dialogue: Thinking Routine Selector

## User

중2 사회 민주주의 단원 도입에서 학생 생각을 먼저 끌어내고 싶어.

## Assistant

바로 활동을 만들기보다 어떤 사고를 보이게 할지 먼저 고르겠습니다.

A. 학생의 기존 생각과 질문을 드러내기  
B. 자료를 관찰하고 근거를 찾기  
C. 여러 관점을 비교하기  
D. 수업 후 생각 변화를 성찰하기  
E. 기타: 직접 적기  

추천은 A입니다. 단원 도입에서는 학생의 기존 생각과 궁금증이 이후 탐구 질문으로 이어져야 합니다.

## User

A가 좋아.

## Assistant

추천 루틴은 `Think-Puzzle-Explore`입니다.

수업 흐름:

1. Think: 민주주의에 대해 이미 알고 있는 것을 씁니다.
2. Puzzle: 아직 헷갈리거나 궁금한 점을 씁니다.
3. Explore: 이 질문을 확인할 방법을 정합니다.

평가 증거:

- 학생이 민주주의를 제도 이름이 아니라 생활 속 문제와 연결하는가?
- 질문이 단순 정보 확인을 넘어 탐구 가능한 질문으로 바뀌는가?
