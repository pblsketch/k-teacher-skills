# Sample Dialogue: Differentiate Lesson Pathways

## User

중1 수학 일차방정식 활용 문제에서 학생 편차가 너무 커.

## Assistant

수준별 문제를 바로 만들기보다 공통 목표를 먼저 확인하겠습니다.

A. 상황을 식으로 나타내기  
B. 방정식을 풀기  
C. 풀이 과정을 설명하기  
D. 실생활 문제를 직접 만들기  
E. 기타: 직접 적기  

추천은 A와 C입니다. 활용 문제에서 학생이 막히는 지점은 계산보다 상황을 식으로 바꾸고 설명하는 과정일 가능성이 큽니다.

## User

A와 C가 맞아.

## Assistant

세 경로로 설계하겠습니다.

- 기초: 문장 속 수량 관계에 밑줄을 긋고 식 틀을 완성합니다.
- 표준: 상황을 식으로 세우고 풀이를 설명합니다.
- 심화: 조건을 하나 바꿔 새 문제를 만들고 해를 비교합니다.

공통 평가 증거는 “상황을 식으로 표현한 근거를 말로 설명할 수 있는가”입니다.
