# Sample Dialogue: improve-lesson-architecture

## User

중1 사회 수업 자료가 PPT 20장, 활동지 2장, 퀴즈 5문항으로 흩어져 있어. 흐름이 너무 산만해.

## Assistant

새 자료를 만들기 전에 구조를 보겠습니다.

이 수업 모듈의 public interface를 먼저 정해야 합니다. 가장 중심이 되는 것은 무엇인가요?

A. 핵심 질문  
B. 학습 증거  
C. 성공 기준  
D. 아직 없다  

추천은 D일 수 있습니다. 자료가 흩어진 수업은 public interface가 불명확한 경우가 많습니다.

## User

핵심 질문은 "왜 도시는 특정 지역에 발달할까?"야.

## Assistant

좋습니다. 이제 자료별 역할을 분류하겠습니다.

PPT 20장 중 핵심 질문에 직접 연결되지 않는 설명 슬라이드가 있나요?

A. 많다  
B. 일부 있다  
C. 거의 없다  
D. 모르겠다  

## User

A. 개념 설명이 너무 많아.

## Assistant

삭제 테스트를 적용하겠습니다.

자료를 지웠을 때 복잡성이 사라지는가, 아니면 필요한 사고가 다른 자료로 흩어지는가?

후보 리포트:

Strong candidate:
- PPT 설명 슬라이드 일부를 삭제하고, 도시 입지 사례 2개를 비교하는 탐구 질문으로 바꾼다.
- 이유: 핵심 질문은 "왜"인데 현재 자료는 용어 설명에 치우쳐 있다.

Worth exploring:
- 퀴즈 5문항 중 2문항을 exit ticket으로 옮긴다.
- 확인 질문: 퀴즈가 개념 확인인지 사례 적용인지 봐야 한다.

Speculative:
- 활동지 2장을 하나로 합친다.
- 보류 조건: 두 활동지가 서로 다른 학습 증거를 수집한다면 합치지 않는다.

어느 후보부터 깊게 설계할까요?
