# PBL design

K-Teacher Skills "pbl-design-workflow" workflow를 시작한다.

**Chain:** `zoom-out-lesson` → `pbl-design-coach` → `assessment-first-design` → `rubric-quality-guard` → `to-lesson-brief`
**Default profile:** Deep (threshold 0.15, max 12 rounds)

사용자 요청:
```
$ARGUMENTS
```

## 진행 절차

1. **Round 0:** `skills/lesson-design/zoom-out-lesson/SKILL.md` 로딩 → Gate v2 banner → topology 잠금(보통 단원·다중).
2. **상위 맥락:** 차시 활동이 아니라 단원·학기 흐름에서 PBL 정당성 점검.
3. **PBL 설계:** `pbl-design-coach`로 driving question · 실제 문제 · 학생 역할 · 청중 · 산출물 정의.
4. **과정 평가 설계:** 협업·탐구·반성 등 과정 평가 비중을 명시. 개인 학습 증거와 모둠 산출물 구분.
5. **루브릭 점검:** `rubric-quality-guard`로 과정·산출물 루브릭 정렬 확인.
6. **Brief 정리:** `to-lesson-brief`.

산출물부터 정하기 금지. 실제 문제·청중이 먼저. `references/pbl-design.md` 참조.
