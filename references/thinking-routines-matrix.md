# Thinking Routines Matrix

사고 루틴을 고를 때는 루틴 이름보다 **보이게 만들 사고**를 먼저 정한다.

## Purpose map

| 사고 목적 | 추천 루틴 | 적합한 수업 순간 | 학생 기록 |
|---|---|---|---|
| 관찰과 질문 | See-Think-Wonder | 자료 첫 제시 | 본 것, 생각한 것, 궁금한 것 |
| 배경지식 활성화 | K-W-L | 단원 도입 | 아는 것, 알고 싶은 것, 배운 것 |
| 주장과 근거 | Claim-Support-Question | 토론 전후 | 주장, 근거, 남은 질문 |
| 다관점 탐색 | Circle of Viewpoints | 사회·문학 쟁점 | 관점별 생각 |
| 장단점 판단 | P-M-I | 대안 비교 | 좋은 점, 나쁜 점, 흥미로운 점 |
| 개념 형성 | Think-Puzzle-Explore | 탐구 질문 만들기 | 생각, 의문, 탐구 방법 |
| 성찰 | I Used to Think, Now I Think | 수업 정리 | 이전 생각, 바뀐 생각 |
| 피드백 | Two Stars and a Wish | 산출물 개선 | 강점 2개, 바람 1개 |

## Selection rules

- 도입에는 정답 확인 루틴보다 질문 생성 루틴을 우선한다.
- 탐구 중에는 근거와 관점을 드러내는 루틴을 우선한다.
- 정리에는 생각 변화를 보이게 하는 루틴을 우선한다.
- 루틴 결과가 다음 발문, 활동, 평가 증거로 이어지지 않으면 쓰지 않는다.

## Facilitation notes

- 학생에게 루틴의 목적을 짧게 말한다.
- 첫 사용 때는 교사가 예시 하나를 모델링한다.
- 기록 양식은 간단해야 한다.
- 루틴을 반복해 교실 언어로 만든다.
