# Rubric Quality

좋은 루브릭은 과제 요구사항 목록이 아니라 학습의 질을 설명한다.

## Criteria rules

평가 준거는 다음을 만족해야 한다.

- 성취기준이나 학습 목표와 직접 연결된다.
- 학생 작품이나 수행에서 관찰 가능하다.
- 서로 독립적이다.
- 전체 학습 결과를 충분히 설명한다.
- 과제 부품이 아니라 학습의 질을 본다.

## Common problems

| 문제 | 예 | 수정 방향 |
|---|---|---|
| 과제 구성요소를 준거로 씀 | 표지, 그림, 분량 | 주장의 명확성, 근거의 타당성 |
| 평가적 표현만 있음 | 우수함, 보통, 미흡 | 관찰 가능한 수행 설명 |
| 수량만 셈 | 근거 3개 이상 | 근거가 주장과 연결되는 정도 |
| 성취기준 밖 준거 | 태도, 예쁨 | 성취기준의 지식·기능과 연결 |

## Level descriptor rules

- 같은 준거 안에서는 같은 측면을 수준별로 다룬다.
- 낮은 수준도 결핍 낙인이 아니라 현재 수행을 설명한다.
- 학생이 읽고 무엇을 고칠지 알 수 있어야 한다.
- 수준 수는 3~5단계가 적당하다.

## Student-friendly conversion

- "논리성이 우수함" → "주장과 근거가 자연스럽게 연결된다."
- "자료 활용 미흡" → "자료를 제시했지만 주장을 뒷받침하는 설명이 부족하다."
- "창의적임" → "익숙한 해결책과 다른 대안을 제안하고 이유를 설명한다."
