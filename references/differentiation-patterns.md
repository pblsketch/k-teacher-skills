# Differentiation Patterns

개별화는 같은 목표를 다른 경로로 달성하게 하는 설계다.

## Three-pathway pattern

| 경로 | 지원 방식 | 과제 특성 | 주의점 |
|---|---|---|---|
| 기초 | 예시, 문장틀, 단계 카드 | 구조화된 수행 | 목표 삭제 금지 |
| 표준 | 핵심 절차 독립 수행 | 성취기준 직접 수행 | 과도한 설명 금지 |
| 심화 | 전이, 비교, 비판, 창안 | 더 깊은 사고 | 문제 수만 늘리지 않기 |

## Barrier-based supports

- 어휘 장벽: 핵심어 사전, 그림, 예문
- 배경지식 장벽: 사전 사례, 짧은 영상, 경험 연결
- 읽기 장벽: 문단 나누기, 표시 읽기, 요약 틀
- 쓰기 장벽: 문장 시작어, 개요 틀, 말로 먼저 설명
- 협업 장벽: 역할 카드, 개인 준비 시간
- 실행 기능 장벽: 시간표, 체크리스트, 중간 제출

## Choice board rules

- 모든 선택지는 같은 목표를 향해야 한다.
- 선택지는 난이도 차이가 아니라 표현 경로 차이일 수 있다.
- 공통 평가 준거를 먼저 정한다.
- 선택 이유를 쓰게 하면 무작위 선택을 줄일 수 있다.

## Flexible grouping

- 그룹은 고정 등급이 아니라 임시 지원 단위다.
- 학생에게 그룹 이름을 수준명으로 붙이지 않는다.
- 그룹 이동 가능성을 열어 둔다.
