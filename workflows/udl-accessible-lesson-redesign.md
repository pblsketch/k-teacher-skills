# Workflow: UDL Accessible Lesson Redesign

수업 자료나 활동은 있지만 일부 학생에게 장벽이 큰 경우 사용한다.

```text
improve-lesson-architecture
→ udl-barrier-remover
→ lesson-prototype
→ to-lesson-brief
```

## Checks

- 목표와 평가 증거를 유지했는가?
- 참여/표상/행동과 표현 장벽을 모두 보았는가?
- 디지털 도구가 없어도 가능한 대안이 있는가?
- 학생 선택권이 생겼는가?
- 지원이 낙인이 되지 않는가?
