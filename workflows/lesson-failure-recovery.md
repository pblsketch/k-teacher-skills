# Workflow: Lesson Failure Recovery

수업이 잘 안 되었고 다음 차시를 어떻게 바꿀지 진단할 때 사용한다.

## Chain

```text
diagnose-lesson-failure
→ zoom-out-lesson
→ lesson-prototype
→ to-lesson-brief
```

## Entry signals

- 수업이 망했어
- 학생들이 못 따라왔어
- 활동이 실패했어
- 다음 차시 어떻게 바꾸지

## Exit artifact

- 관찰 증거
- 반증 가능한 원인 가설
- 다음 차시 최소 수정 prototype
- 수업 회복 브리프
