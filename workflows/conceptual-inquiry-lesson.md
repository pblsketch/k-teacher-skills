# Workflow: Conceptual Inquiry Lesson

성취기준 기반 수업을 개념 기반 탐구로 깊게 재설계할 때 사용한다.

```text
grill-with-curriculum
→ concept-based-inquiry-designer
→ thinking-routine-selector
→ assessment-first-design
→ to-lesson-brief
```

## Checks

- 성취기준 핵심 동사를 확인했는가?
- 개념적 렌즈와 일반화가 있는가?
- 사실적/개념적/논쟁적 질문이 균형을 이루는가?
- 사고 루틴이 탐구 질문과 연결되는가?
- 평가 증거가 일반화와 전이를 확인하는가?
