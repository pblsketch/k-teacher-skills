# Workflow: Differentiated Lesson Redesign

학생 편차, 참여 장벽, 기초학력 지원이 중요한 수업을 재설계할 때 사용한다.

```text
diagnose-lesson-failure
→ udl-barrier-remover
→ differentiate-lesson-pathways
→ lesson-prototype
→ to-lesson-brief
```

## Checks

- 학생 탓이 아니라 관찰 가능한 장벽을 찾았는가?
- 참여/표상/표현 장벽을 구분했는가?
- 모든 경로가 같은 핵심 목표를 향하는가?
- 기초/표준/심화 경로가 낙인이 되지 않는가?
- 공통 평가 증거가 유지되는가?
