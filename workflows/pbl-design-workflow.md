# Workflow: PBL Design

실생활·지역사회 문제를 중심으로 프로젝트 수업을 설계할 때 사용한다.

```text
zoom-out-lesson
→ pbl-design-coach
→ assessment-first-design
→ rubric-quality-guard
→ to-lesson-brief
```

## Checks

- 실제 문제가 있는가?
- driving question이 검색형 질문이 아닌가?
- 학생 역할과 청중이 분명한가?
- 개인 학습 증거와 모둠 산출물이 모두 있는가?
- 과정 평가가 최종 발표보다 먼저 설계되었는가?
