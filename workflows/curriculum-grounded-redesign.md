# Workflow: Curriculum-Grounded Redesign

성취기준, 교육과정, 기존 자료를 기준으로 수업을 점검하거나 재설계할 때 사용한다.

## Chain

```text
grill-with-curriculum
→ zoom-out-lesson
→ assessment-first-design
→ improve-lesson-architecture
→ to-lesson-brief
```

## Entry signals

- 성취기준이랑 맞는지 봐줘
- 기존 활동지를 교육과정에 맞게 바꾸고 싶어
- 이 평가가 목표를 제대로 재는지 모르겠어

## Exit artifact

- Curriculum-context summary
- Lesson decision record 후보
- 정렬된 평가 증거
- 재구조화된 수업 모듈
