# Workflow: Material Architecture Improvement

기존 PPT, 활동지, 퀴즈, 루브릭, 피드백 문장이 흩어져 수업 흐름이 산만할 때 사용한다.

## Chain

```text
improve-lesson-architecture
→ assessment-first-design
→ lesson-prototype
→ to-lesson-brief
```

## Entry signals

- 자료가 많은데 흐름이 산만해
- PPT와 활동지가 따로 노는 것 같아
- 수업 구조를 깊게 만들고 싶어

## Exit artifact

- 수업 모듈 public interface
- 삭제 테스트 결과
- 개선 후보 리포트
- 선택된 구조 개선안
